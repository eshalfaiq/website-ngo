# Baseerat - Science For Everyone

### What is this project?
Baseerat is a student-led project on a mission to make STEM accessible for Pashto-speaking kids in rural KPK. We're tearing down language barriers with free Pashto physics lectures, community book donations, and real mentorship to prove that science really is for everyone! This repository holds the landing page for our initiative. 

### How I built it
I spent about 11 hours building this site completely from scratch using pure HTML, CSS and Vanilla JS. The page features a bilingual hero section (English and Pashto), a custom CSS Flexbox grid to display our recent milestones and a few interactive hover effects and JS alerts. 

### How to run it
Since this is a static website, you don't need to install any frameworks or dependencies to see it. 
1. Download or clone this repository to your computer.
2. Open the project folder.
3. Double-click the `website.html` file to open it in your default web browser.
